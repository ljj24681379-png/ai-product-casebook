# 高考志愿 AI 助手：搜索承接与个性化决策服务

## 用户问题

高考需求会随考试周期从信息查询转向志愿决策。志愿决策类问题全周期约占 33%，出分后升至 60%—71%。普通问答难以结合考生个人情况，无法支撑连续、专业的决策过程。

## 产品判断

产品不能只增加院校信息，而要把服务目标从“查询信息”升级为“辅助个人决策”：先用搜索入口降低使用门槛，再在咨询过程中逐步澄清考生条件，围绕真实志愿流程组织比较与连续咨询。

## 关键方案

- 设计搜索卡片、专题页和志愿服务入口，连接搜索流量与专业服务；
- 通过条件澄清、方案比较和连续咨询组织决策过程；
- 划分专业数据、模型解释和交互呈现的职责；
- 组织 6 轮、3,200 条专项评测，覆盖 31 个省份以及普通、艺术、体育等考生类型。

## 结果

- 高考 Box 点击率达到 53.76%，约为上年 13.60% 的 3.95 倍；
- 志愿方案入口累计获得 30.94 万次点击；
- 6—7 月承接 43.15 万次成功提问，覆盖 28.87 万个会话。

## 复盘

垂类 Agent 的竞争力不只来自回答质量。入口承接、条件澄清、专业工具、持续对话和专项评测需要被设计成一个完整服务链路。
